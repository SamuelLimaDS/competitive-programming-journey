# competitive-programming-journey
Preparação para a Maratona SBC de Programação 2026 (ICPC). Repositório dedicado aos meus estudos em programação competitiva com C++ e Python, focando em algoritmos, estruturas de dados, resolução de problemas, contests e evolução contínua através de plataformas como Beecrowd, CSES e Codeforces.
